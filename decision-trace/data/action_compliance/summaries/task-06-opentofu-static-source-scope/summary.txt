Current
- Retain the unevaluated `hcl.Expression` of the module `source` attribute on `ModuleCall` during module-call parsing, preserving it even if eager address decoding yields diagnostics (Task prompt; Artifact 003).
- Preserve the retained source `hcl.Expression` when an override replaces a module source in `internal/configs/module_merge.go` (Task prompt; Artifact 003).
- Add a parser test verifying that a `source = local.module_source` traversal expression survives decoding (Task prompt).
- This aligns with the accepted static evaluation RFC that mandates retaining the module source expression for init-time evaluation in module scope (Artifact 002: https://github.com/opentofu/opentofu/pull/1649, https://github.com/opentofu/opentofu/blob/8f8e0aa4aa92980882c2df3209c75466629bce4c/rfc/20240513-static-evaluation.md).

History
- Baseline at pinned commit `opentofu/opentofu@3fdc8090501234c55093078255969ecbc46f2fe2`: `internal/configs/module_call.go` eagerly decoded the module source attribute into a string and address, discarding the expression as a first-class field, while `internal/configs/module_merge.go` only propagated source address fields upon overrides (Artifact 003).
- Proposed and Rejected: Block-label interpolation was proposed in the initial draft of Issue #1042 but was rejected and marked out of scope due to rename/identity complexity; module block labels remain fixed parser identity strings (Artifact 001: https://github.com/opentofu/opentofu/issues/1042, https://github.com/opentofu/opentofu/issues/1042#issuecomment-1875588374; Artifact 002; Artifact 003).
- Subsequent / Broader Scope: PR #1718 merged full static-evaluation base, module-source support, and backend configuration support for OpenTofu 1.8 (Artifact 002: https://github.com/opentofu/opentofu/pull/1718).

Scope
- In Scope: Modifying module-call parsing and merge handling to retain and propagate the unevaluated `hcl.Expression` on `ModuleCall`, plus adding the specified parser test (Task prompt; Artifact 003).
- Out of Scope: Implementing the evaluator itself (Task prompt). Block-label interpolation and evaluation (Artifact 001: https://github.com/opentofu/opentofu/issues/1042; Artifact 002). Full static-evaluation runtime and backend configuration evaluation (Artifact 002).

Uncertainty
- The sources do not specify the exact field name or type definition to be used on `ModuleCall` to store the unevaluated `hcl.Expression`.
- The exact test file path and structure for the focused parser test are not established in the sources.
