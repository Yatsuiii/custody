Current
- `Lib/_pyio.py`'s `TextIOWrapper` and text-mode `open()` must accept `encoding="locale"` and resolve it to the current locale encoding (Raw Task Prompt; https://peps.python.org/pep-0597/).
- Binary mode `open()` must unconditionally reject any non-`None` encoding value (https://github.com/python/cpython/commit/cfa176685a5e788bafc7749d7a93f43ea3e4de9f; Pinned code boundary).
- `"locale"` is treated as a text-encoding feature rather than a codec alias because the locale can change at runtime and `TextIOWrapper` handles device-encoding behavior (https://peps.python.org/pep-0597/).
- A focused regression test exercising both text-mode `open()` and `TextIOWrapper` with `encoding="locale"` is added in `Lib/test/test__pyio_locale.py` (Raw Task Prompt; Pinned code boundary).
