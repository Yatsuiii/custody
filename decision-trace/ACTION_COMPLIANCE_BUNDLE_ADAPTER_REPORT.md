## 2. Adapter architecture and files

The new path is:

```text
neutral frozen bundle
  -> LocalBundleSource / BundleArtifact
  -> existing Vertex generator + existing quote verifier
  -> model-reported Decision fields (invalid claims retained as failures)
  -> unchanged AuthorityProof resolver
```

The adapter is transport-only; it does not decide accepted/rejected,
superseded/reverted, governing, scope, role, or partial acceptance.  It
generates neutral IDs from artifact identity and record position and ignores
model-provided IDs.  `ACTION_COMPLIANCE_BUNDLE_INGEST_AUDIT.md` documents the
live path and this substitution boundary.

Relevant changed/new files:

- `app/ingest.py` — generic bundle extraction entry point; existing live
  GitHub functions and resolver calls are unchanged.
- `app/bundle_source.py` — neutral `BundleArtifact`, `SourceBundle`, and strict
  local layout validation.
- `app/action_compliance_context.py` — common raw-prefix serializer and
  condition-exclusive context assembler.
- `ACTION_COMPLIANCE_BUNDLE_INPUT_POLICY.json` — machine-readable allow/deny
  boundary.
- `scripts/prepare_action_compliance_bundle.py` — one-time fixture preparation
  of the literal request and neutral artifact copies.
- `scripts/run_action_compliance_bundle_ingestion.py` — pre-ground-truth
  Decision/proof freeze command.
- `scripts/assemble_action_compliance_context.py` and
  `scripts/verify_action_compliance_contexts.py` — context parity and size
  checks.
- `scripts/generate_action_compliance_summaries_claude.py` — frozen Arm-B
  summary generation with no tools.
- `scripts/dry_run_action_compliance.py` and `scripts/dry_run_grader.py` —
  no-model blind orchestration smoke test.
- `scripts/replay_action_compliance_sanity.py` — fresh human-patch replay.
- `ACTION_COMPLIANCE_RUN_PROTOCOL.md` and
