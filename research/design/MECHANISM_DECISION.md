# Mechanism Decision

Verdict: DESIGN-CAUTION

Architecture A—central structural admission envelopes, action-scoped authority,
operation-level relay policy, authoritative-time compromise windows, and a
replacement-only repair overlay—is coherent enough for the isolated falsifier
in `DESIGN_FALSIFIER.md`. It is not authorized for production implementation.

## Why this is the minimum defensible design

- E2A requires an upstream authority signal and a relay/origin distinction;
  tool identity alone is already falsified.
- E2C requires an explicit cross-invocation parent signal; exact content hash
  cannot be tuned to survive even one changed byte.
- E1 shows direct multi-parent edges and ordinary graph closure are sufficient;
  no hypergraph or semantic edge inference is required.
- Case K requires authoritative-time root selection before the existing closure
  can become interval-specific.
- E2B's benign control requires retaining transformed provenance and
  informational utility, while the hallucination case prevents free-form text
  from automatically retaining action authority.
- I8 forbids pruning a bad parent and raising unchanged content; restoration is
  a new record produced by a fresh transform.

Candidate B lacks the facts the failures expose. Candidate C adds keys and
distributed signers for a store-forgery adversary not exercised here and still
cannot prove free-form semantic fidelity. Architecture A adds the least new
trusted machinery that can be tested against all measured failure shapes.

## DDIA Review

Verdict: architecturally unshippable for production; valid only as an isolated
experimental design.

Chosen design: immutable admission envelopes and direct-parent DAG as the
source of truth; logical support closure; pointwise authority meet; append-only
compromise-window generations; current-generation action overlay; idempotent
replacement-only repair.

Key invariants: no amplification, complete declared parents, unknown context
never becomes fresh authority, active-window descendants are ineffective,
outside-window-only support remains effective, and unchanged records never gain
authority during repair.

Rejected alternatives: persistent ambient taint lacks cross-invocation facts;
semantic matching invents edges; signed distributed receipts target an
unmodeled storage adversary and expand key/clock failure modes; in-place support
pruning can elevate unchanged content.

Failure modes: incomplete context capture, missing authoritative time, policy
misclassification, crash between revocation phases, concurrent affected writes,
stale action caches, downstream deletion failure, legacy schema, and receipt
replay conflicts. The required fail-closed behavior is specified in
`DYNAMIC_TRUST_MODEL.md` and `REPAIR_SEMANTICS.md`.

Acceptance gates: run the fixed metrics and crash probes in
`DESIGN_FALSIFIER.md`; demonstrate atomic envelope admission, current-generation
action checks, exact affected closure, unaffected-sibling preservation, and
stable replay before any production branch exists.

Smallest proof artifact:
`research/experiments/E2D_DESIGN_FALSIFIER/result.json`, generated by a
deterministic experimental harness with no production edits.

Unresolved risks: current ADK/Memory Bank paths have not proved complete
record-id context capture; only Firestore currently supplies the required
authoritative timestamp shape; operation roles/action scopes are not yet
implemented; and the crash-safe overlay/outbox protocol has not run.
