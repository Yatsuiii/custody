  system's Python 3.14.7 — no incompatibility observed for the offline
  scripts).
- Core deps: `requests>=2.31`, `numpy>=1.24`, `matplotlib>=3.7` — all
  already present in this machine's environment, confirmed by direct

  discipline.
- Optional (only for `code/mem0_eval.py`, not attempted here): `mem0ai`,
  `sentence-transformers`, `qdrant-client`.

  JRE 11+ and `tla2tools.jar`, per `formal/DOWNLOAD_TLA.md`.
- **All LLM-backed scripts require `OPENROUTER_API_KEY`** (`code/llm.py`:
  hard `sys.stderr` fatal if unset). No key was obtained or used in this
  experiment, per the session's non-goals.
- Cost: the repository's own already-logged `results/results_laundering.json`
  reports `$0.14562...` for one full 8-model x 4-channel x 3-scenario x
  5-trial sweep — genuinely cheap if a key were ever authorized, but this
  experiment did not spend anything.
- Network: only the offline scripts were run, which perform no network
  calls (confirmed by reading their imports — `code/test_monitor.py` and
  `code/check_invariant.py` import only `memory`/`monitor`, no `llm`,
  no `requests`).
- Hardware: trivial (pure-Python, no GPU, sub-second runtime observed).

**Result: PASS.** Both commands ran to completion on the first attempt,
with real, non-trivial output matching their docstrings' stated claims. No
environment compatibility fix of any kind was needed — no patch, so
nothing to log per the "record original failure / exact patch / why
environment-only" instruction; this section states plainly that no fix was
required rather than omitting it.

`check_invariant.py`'s own docstring is worth restating precisely because
it is an unusually strong claim, verified rather than merely quoted: it is
an **exhaustive, bounded model check run directly against the same
`monitor.py` implementation the rest of the harness uses** (not a separate
hand-abstraction), across all `0..3`-size supporting-item combinations and
all authorization-state combinations, and it additionally proves a
*necessity* result (`N`): disabling write-time binding makes the safety
property violable, i.e. the mechanism is load-bearing, not decorative.
This is a genuinely more rigorous reproducible claim than most benchmark
repos ship, and it reproduced cleanly.

`code/stress_independence.py`, `code/lineage_policy.py`,
